{{ include "weebo-operator.notes" . }}

1. Connect a Stalwart with an API token:

     kubectl -n {{ .Release.Namespace }} create secret generic stalwart-admin --from-literal=token=<token>

     kubectl apply -f - <<YAML
     apiVersion: stalwart.weebo.io/v1alpha1
     kind: StalwartInstance
     metadata:
       name: main
     spec:
       url: https://stalwart.example.com
       tokenSecretRef:
         namespace: {{ .Release.Namespace }}
         name: stalwart-admin
         key: token
     YAML

2. Then declare a StalwartDomain (cluster-scoped, `deletionPolicy: Orphan`)
   on it (`spec.instanceRef: {name: main}`, or none: the only instance).

Argo CD: paste the health check of the
{{ include "weebo-operator.fullname" . }}-argocd-health ConfigMap into argocd-cm under
`resource.customizations.health.stalwart.weebo.io_*`.
