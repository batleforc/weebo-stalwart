- **API version:** `stalwart.weebo.io/v1alpha1`
- **Scope:** Cluster
- **Short names:** none
- **Guide:** [The allow-list](/docs/guides/allow-list)

Namespace allow-list for the namespaced account kinds, enforced by the
admission webhook (CREATE/UPDATE) and re-checked by every reconciler
before any Stalwart call. It governs the CRs bound to a
`StalwartInstance` (shared by every namespace); a CR bound to a
`StalwartLocalInstance` is bounded by its namespace's own token instead.

While no `StalwartNamespacePolicy` exists, everything is allowed. As
soon as one exists, a namespaced CR is only accepted if some `Allow`
rule matches its namespace and kind and covers the domains and names
it asks for — and no `Deny` rule matches. Rules of every policy are
pooled; a `Deny` always wins.

## Example

```yaml
apiVersion: stalwart.weebo.io/v1alpha1
kind: StalwartNamespacePolicy
metadata:
  name: my-namespacepolicy
spec:
  rules:
    - namespaces:
        - forgejo
      allowedKinds:
        - StalwartServiceAccount
      allowedDomains:
        - example.internal
      allowedNames:
        - forgejo
        - noreply
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| [`rules`](#spec.rules) | `object[]` | yes |  |  |

### `spec.rules[]` [#spec.rules]

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `allowedDomains` | `string[]` | no |  | `StalwartDomain`s (by `metadata.name`) the objects may live in. Unset: any. On a `Deny` rule: only deny requests in one of these. |
| `allowedKinds` | `string[]` | yes |  | Values: `"StalwartServiceAccount"`, `"StalwartAccount"`, `"StalwartGroup"`, `"StalwartMailingList"` |
| `allowedNames` | `string[]` | no |  | Local-parts the objects may claim: an object's name **and** each of its aliases must be listed. Unset: any. On a `Deny` rule: deny requests whose name or any alias is listed — the way to reserve names (`postmaster`, `admin`…) for every namespace. |
| `effect` | `string` | no | `"Allow"` | Values: `"Allow"`, `"Deny"` |
| `namespaces` | `string[]` | yes |  | Namespace names, `*` for all, or a prefix glob like `team-*`. |
